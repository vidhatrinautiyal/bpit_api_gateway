07 / ABOUT THE BUILD

One gateway.
Three levels of trust.

BPIT API Gateway is a local attendance platform that puts authentication, role-based access, and service data behind one reliable entry point.

OWNER

Vidhatri Nautiyal

Summer training project focused on building a practical, secure API foundation for campus workflows.

STACK

Node / Express / MySQL

JWT, Sequelize, native password hashing, and a vanilla browser interface.

MODEL

User → Role → Permission

Normalized join tables make the authorization model easy to extend.
